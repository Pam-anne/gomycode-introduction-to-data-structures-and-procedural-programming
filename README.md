# Data Structures and Procedural Programming Checkpoint

This repository contains algorithmic solutions for the Data Structures and Procedural Programming checkpoint. The solutions focus on array manipulation, nested loops, and the use of procedures and functions.

## Contents

### 1. Sum of Distinct Elements
**Problem:** Given two sets of elements, find the sum of all distinct elements (elements present in one set but not the other).
- **Logic:** The algorithm iterates through the first set and checks if each element exists in the second set. If not, it adds it to the sum. The process is then repeated for the second set relative to the first.
- **Key Concepts:** Arrays, Nested Loops, Boolean flags.

### 2. Dot Product & Orthogonality
**Problem:** Write a procedure/function to calculate the dot product of two vectors and determine if they are orthogonal (dot product = 0).
- **Logic:** - A **Procedure** is used to calculate the dot product and store the result in a variable passed by reference.
    - A **Function** is used to return the dot product value directly.
    - An algorithm checks for orthogonality across multiple pairs of vectors.
- **Key Concepts:** Procedures vs. Functions, Passing parameters by reference, Linear Algebra logic.

## How to Run
The solutions are written in pseudo-code format following standard algorithmic logic. You can find the logic in the `.algo` files within this repository.
